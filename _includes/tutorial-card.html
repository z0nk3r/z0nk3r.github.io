{% comment %} Card meta is descendant-aware: a group's card counts every chapter anywhere below it, not just direct ones. All joins are URL-based (the tutorials collection holds both topics and chapters; chapter: presence discriminates). The topic's own url is already the "/"-terminated descendant prefix - do NOT append another "/" (that would make the prefix "/tutorials/a//" and match nothing), and its termination makes sibling false-positives (/tutorials/a/ vs /tutorials/ab/...) impossible. Starts-with is slice-to-prefix-length (Liquid has no startswith; `contains` matches anywhere). The child/"N series" count must exclude chapters - a group's DIRECT chapters share its parent URL, and without the unless-filter they'd inflate the series count. {% endcomment %} {% assign card_prefix = include.topic.url %} {% assign card_chapter_count = 0 %} {% assign card_minutes = 0 %} {% assign card_child_count = 0 %} {% for card_doc in site.tutorials %} {% assign card_head = card_doc.url | slice: 0, card_prefix.size %} {% if card_head == card_prefix and card_doc.url != card_prefix %} {% if card_doc.chapter %} {% assign card_chapter_count = card_chapter_count | plus: 1 %} {% assign card_minutes = card_minutes | plus: card_doc.read_time %} {% else %} {% assign card_parent = card_doc.url | split: "/" | pop | join: "/" | append: "/" %} {% if card_parent == card_prefix %} {% assign card_child_count = card_child_count | plus: 1 %} {% endif %} {% endif %} {% endif %} {% endfor %}
