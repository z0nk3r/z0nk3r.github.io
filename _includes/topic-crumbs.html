{% comment %} Renders the full breadcrumb trail for a tutorials-tree page: Home / Tutorials / / ... / Params: topic - the topic key (a path like "basic-skills/basic-python"; every "/"-separated prefix is looked up as its own topic doc) link_last - true renders the final (deepest) topic crumb as a link too (chapter pages want this - the chapter itself is the current page); false renders it as plain text (topic pages - it IS the current page). Ancestors are always linked when their doc exists. Renders only the / crumb items and separators for the topic chain, INCLUDING the leading Home / Tutorials pair - the caller supplies the surrounding
and any trailing chapter crumb. Liquid scoping note: assigns inside an include write to the CALLER's scope (Liquid has no include-local scope), so every variable here is crumb_-prefixed to guarantee it can't clobber the caller's own variables (tutorial-chapter.html has `chapters`/`topic_doc`/`chapter_pos` live when this runs). A missing ancestor doc (nested topic whose parent file doesn't exist yet) renders as plain unlinked text of the raw path segment rather than an empty link - the page still builds, the trail stays readable, and the gap is obvious to the author. {% endcomment %} ⌂Home / ▣Tutorials {% assign crumb_segments = include.topic | split: "/" %} {% assign crumb_prefix = "" %} {% for crumb_seg in crumb_segments %} {% if forloop.first %}{% assign crumb_prefix = crumb_seg %}{% else %}{% assign crumb_prefix = crumb_prefix | append: "/" | append: crumb_seg %}{% endif %} {% assign crumb_doc = site.tutorial_topics | where: "topic", crumb_prefix | first %} / {% if crumb_doc == nil %} ▣{{ crumb_seg }} {% elsif forloop.last and include.link_last != true %} ▣{{ crumb_doc.title }} {% else %} ▣{{ crumb_doc.title }} {% endif %} {% endfor %}
